+------------------------------------------------------------------------------+
|                         SYSTEMD DAEMON (PID 1 - ROOT)                        |
|   /etc/systemd/system/*.service  |  /lib/systemd/system/*.service            |
|   Dosya İzni Doğrulaması (0644 root:root) & Drop-in Override Kontrolü        |
+------------------------------------------------------------------------------+
                                      |
                                      v
     [1. SERT GÜVENLİK FİLTRESİ: KİMLİK & AYRICALIK KISITLAMALARI]
     +------------------------------------------------------------+
     | • User=appuser, Group=appuser (Ayrılmış Sistem Hesabı)     |
     | • NoNewPrivileges=yes (prctl: PR_SET_NO_NEW_PRIVS)         |
     |   ==> SUID/SGID istismarı ve yetki yükseltme engellenir!   |
     +------------------------------------------------------------+
                                      |
                                      v
     [2. SANDBOXING & NAMESPACE İZOLASYONU (KERNEL SUBSYSTEMS)]
     +------------------------------------------------------------+
     | • ProtectSystem=strict  ==> /usr, /boot, /etc salt-okunur  |
     | • ProtectHome=yes       ==> /home, /root tamamen gizlenir  |
     | • PrivateTmp=yes        ==> Sürece özel izole /tmp alanı   |
     | • PrivateDevices=yes    ==> /dev ham aygıt erişimi kilitli |
     | • ProtectKernelTunables ==> /proc/sys, /sys salt-okunur    |
     | • ProtectControlGroups  ==> /sys/fs/cgroup manipülasyonu   |
     |                           engellenir                       |
     +------------------------------------------------------------+
                                      |
                                      v
     [3. LINUX CAPABILITIES & SOKET KISITLAMALARI]
     +------------------------------------------------------------+
     | • CapabilityBoundingSet=CAP_NET_BIND_SERVICE               |
     |   (CAP_SYS_ADMIN, CAP_SYS_PTRACE, CAP_SYS_MODULE yasak!)   |
     | • RestrictAddressFamilies=AF_UNIX AF_INET AF_INET6         |
     | • RestrictRealtime=yes (Gerçek zamanlı DoS engellenir)     |
     +------------------------------------------------------------+
                                      |
                                      v
     [4. GÜVENLİ SERVİS İŞLEMİ (ISOLATED WORKER PROCESS)]
