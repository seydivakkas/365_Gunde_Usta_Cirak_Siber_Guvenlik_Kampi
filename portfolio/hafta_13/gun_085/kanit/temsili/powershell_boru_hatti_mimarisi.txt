================================================================================
G085: POWERSHELL NESNE BORU HATTI (OBJECT PIPELINE) GÜVENLİK MİMARİSİ
================================================================================

Bu şema, Unix bayt/metin boru hattı ile PowerShell .NET Nesne Boru Hattı arasındaki
farkı, nesne akışının adli bilişim ve tehdit avcılığında (threat hunting) nasıl
kullanıldığını ve boru hattı güvenlik zafiyetlerini modeller.

+-------------------------------------------------------------------------------+
|                       UNIX vs. POWERSHELL BORU HATTI FARKI                   |
|                                                                               |
|  UNIX (Metin / Bayt Akışı):                                                   |
|  $ ps aux | grep "mimikatz" | awk '{print $2}'                                |
|  [ Ham Metin ] ---> [ Düzensiz Boşluklar ] ---> [ Kırılgan Regex Ayrıştırma ] |
|                                                                               |
|  POWERSHELL (Yapılandırılmış .NET Nesne Akışı):                               |
|  PS> Get-Process | Where-Object { $_.CPU -gt 10 } | Select-Object -Property Id|
|  [ System.Diagnostics.Process Nesnesi ] ===> Tip Güvenli Özellikler ($_.CPU)  |

+-------------------------------------------------------------------------------+
| 1. STATİK BETİK VE BORU HATTI DENETİMİ (PipelineSyntaxAuditor)                |
|    - Null-Byte Denetimi: 0x00 (\x00) Enjeksiyonunun Engellenmesi (CWE-158)    |
|    - Sözdizimi Doğrulama: Boş pipe (| |) ve havada kalan pipe denetimi (CWE-20)|
|    - IEX Tespiti: ... | Invoke-Expression veya ... | iex Engelleme (CWE-95)   |
|    - Download Cradle: WebClient.DownloadString(...) | iex Tespiti (CWE-829)   |
|    - Obfuscated Base64: -EncodedCommand veya FromBase64String Tespiti (CWE-116)|
|    - Unquoted Path: C:\Program Files\Insecure\... Boşluklu Yol Tespiti (CWE-428)|
