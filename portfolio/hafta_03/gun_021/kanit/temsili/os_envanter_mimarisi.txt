STANDART KARŞILAŞTIRMA ÖZETİ (WINDOWS vs LINUX)
========================================================================================
- Sürüm & EOL         : Windows Server 2022 (20348)     <--> Ubuntu 24.04 LTS (6.8.0)
- Dosya & Şifreleme   : NTFS + BitLocker                <--> ext4 + LUKS2
- Kimlik Denetimi     : Active Directory / SID          <--> PAM / UID 0 / Sudo Grubu
- Savunma Servisi     : MpsSvc (Firewall) + WinDefend   <--> UFW + Auditd
- Yama Mekanizması    : Windows Update / WSUS (KB'ler)  <--> APT / Unattended-Upgrades
