+------------------------------------------------------------------------------+
|                 ÇEKİRDEK KİPİ (KERNEL MODE - RING 0)                         |
|                                                                              |
|  [İşletim Sistemi Çekirdeği: ntoskrnl.exe / vmlinuz]                         |
|  [Aygıt Sürücüleri: Disk, Ağ, Ekran Kartı, Güvenlik Filtreleri]              |
|  - Bellek Sınırı: 0xFFFF800000000000 - 0xFFFFFFFFFFFFFFFF (Çekirdek Alanı)  |
|  - Ayrıcalık: Sınırsız Donanım Denetimi, Tüm Bellek, MSR ve CRx Kayıtçıları |
|                                                                              |
|  +---------------------------+   +---------------------------------------+   |
|  | Çekirdek Havuzu (Pool)    |   | Savunmasız Sürücüler (BYOVD Tehdidi)   |   |
|  | - Non-Paged Pool (DRAM)   |   | - RTCore64.sys, gdrv.sys              |   |
|  | - Paged Pool (Takaslanır) |   | [Saldırgan Yönetici Hakkıyla Yükler;  |   |
|  | - Sayfa Tabloları (CR3)   |   |  Çekirdek Belleğini Keyfi Ezer!]      |   |
|  +---------------------------+   +---------------------------------------+   |
|                                                                              |
|  SAVUNMA MEKANİZMALARI:                                                      |
|  - DSE (Driver Signature Enforcement): Yalnızca geçerli imzalı sürücüler     |
|  - HVCI / VBS (Hipervizör Korumalı Bellek Bütünlüğü): Kod sayfaları kilitli  |
|  - Microsoft Recommended Driver Blocklist: Bilinen BYOVD sürücüleri engelli  |
|  - KASLR (Kernel ASLR) & KPTI (Kernel Page Table Isolation)                  |
