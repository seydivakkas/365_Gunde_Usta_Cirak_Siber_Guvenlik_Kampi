|                          2. RAM KATMANI (ANA BELLEK)                         |
|  - Durum: Uçucu (Volatile), Microsecond hız, DRAM                             |
|  - İşlem Sanal Bellek Alanı (Virtual Address Space - VAS):                   |
|                                                                              |
|    [0x7ffd...] Yığıt (Stack)    : Yerel değişkenler, Fonksiyon çerçeveleri  |
|    [0x55a0...] Öbek (Heap)      : malloc/new dinamik nesneler, Session Token|
|    [0x4006...] BSS / Data       : Genel & Statik Değişkenler                 |
|    [0x4000...] Text (Code)      : Salt-okunur yürütülebilir kod (R-X)        |
|                                                                              |
|  GÜVENLİK TEHDİTLERİ:                                                        |
|  1. Plain Free: free(ptr) sonrası tampon sıfırlanmazsa veri bellekte kalır.  |
|  2. Un-zeroed Heap: Mimikatz / Procdump ile açık metin parola sızdırılır.    |
|  3. Paging / Swap: mlock() yoksa işletim sistemi RAM bloğunu diske yazar!     |
|                                                                              |
|  SAVUNMA MEKANİZMALARI:                                                      |
|  - DEP / NX (Data Execution Prevention)                                      |
|  - ASLR (Address Space Layout Randomization)                                 |
|  - VirtualLock / mlock + SecureZeroMemory()                                  |
