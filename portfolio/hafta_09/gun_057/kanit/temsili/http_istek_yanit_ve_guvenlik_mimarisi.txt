2. HTTP METOTLARI SEMANTIK MATRISI (RFC 7231)
================================================================================
  Metot    | Guvenli (Safe)?  | Esguklu (Idempotent)? | Tipik Kullanim
  ---------+------------------+-----------------------+-------------------------
  GET      | EVET (Durum 0)   | EVET                  | Kaynak okuma/listeleme
  HEAD     | EVET (Gövdesiz)  | EVET                  | Baslik ve meta kontrolu
  POST     | HAYIR            | HAYIR                 | Yeni kaynak yaratma
  PUT      | HAYIR            | EVET                  | Kaynagi tamamen guncelleme
  DELETE   | HAYIR            | EVET                  | Kaynak silme
  OPTIONS  | EVET             | EVET                  | CORS / Izinli metot sorgusu
  TRACE    | EVET (Tehlikeli) | EVET                  | Echo / XST Saldiri Riski!

3. SALDIRI SENARYOLARI VE ENGELLEME MEKANIZMALARI
================================================================================

[A] CRLF ENJEKSIYONU VE HTTP RESPONSE SPLITTING
--------------------------------------------------------------------------------
   Saldirgan Girdisi: /redirect?url=http://site.com%0d%0aSet-Cookie:%20session=fake
   Sunucu Yorumu:
   HTTP/1.1 302 Found\r\n
   Location: http://site.com\r\n
   Set-Cookie: session=fake\r\n  <--- [SALDIRGANIN ENJEKTE ETTIGI BASLIK!]
   \r\n
   <html>...</html>
   SAVUNMA: Tum kullanici girdilerinde %0d, %0a (\r, \n) baytlari filtrelenir!

[B] HTTP REQUEST SMUGGLING (CL.TE / TE.CL DESENKRONIZASYONU)
--------------------------------------------------------------------------------
   On-Uc (Front-End Proxy)           Arka-Uc (Back-End Web Server)
   Content-Length'e Oncelik Verir    Transfer-Encoding: chunked'a Oncelik Verir
             \                                    /
              \                                  /
         +--------------------------------------------+
         | Ayni HTTP Isteğinde Hem CL Hem TE Varsa:   |
         | Sınır Belirsizliği Olusur (Desync)!        |
         | Saldirgan Sonraki Kullanicinin Istegine    |
         | Kendi Gizli Komutunu Yapistirir (Smuggle)  |
         +--------------------------------------------+
   SAVUNMA: RFC 7230 §3.3.3 kurali uyarinca hem CL hem TE iceren istekler
            derhal 400 Bad Request ile dusurulur!

4. OWASP GUVENLIK BASLIKLARI ZIRHI (DEFENSE IN DEPTH)
================================================================================
   +------------------------------------+--------------------------------------+
   | Guvenlik Basligi                   | Engelledigi Saldiri Turu             |
   +------------------------------------+--------------------------------------+
   | Strict-Transport-Security (HSTS)   | SSL Stripping, Man-in-the-Middle     |
   | Content-Security-Policy (CSP)      | Cross-Site Scripting (XSS), Data Exf |
   | X-Frame-Options: DENY              | Clickjacking (UI Redress Attack)     |
   | X-Content-Type-Options: nosniff    | MIME Sniffing, Sahte Resim XSS       |
   | Referrer-Policy                    | Hassas Token ve URL Parametre Sizmasi|
   | Permissions-Policy                 | Kamera, Mikrofon, Konum Yetkisiz Eris|
   +------------------------------------+--------------------------------------+
