BÖLÜM 1: DNS HİYERARŞİK DAĞITIK VERİTABANI AĞACI
================================================================================

                              [ . ] (Root Zone / Kök Sunucular)
                             /      \                  \
                      [ .com ]      [ .org ]          [ .tr ]  (TLD Sunucuları)
                      /      \             \                 \
             [ example ]     [ google ]   [ wikipedia ]     [ metu ] (Yetkili SLD)
             /    |    \
        [ www ] [ api ] [ blog ]                               (Alt Alan Adları)

Sorgu Akışı:
  İstemci -> Yinelemeli Çözümleyici (Recursive Resolver) -> Kök (.) -> TLD (.com) -> Yetkili NS
