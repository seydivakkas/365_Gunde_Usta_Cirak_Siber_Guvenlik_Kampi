1. MEŞRU ARP ÇÖZÜMLEME DÖNGÜSÜ (NORMAL OPERATION)
--------------------------------------------------------------------------------
   İstemci A (192.168.1.50)                                       Ağ Geçidi (192.168.1.1)
   MAC: 52:54:00:12:34:56                                         MAC: 00:1A:2B:3C:4D:01
          |                                                                 |
          |--- (1) ARP Request (Broadcast: FF:FF:FF:FF:FF:FF) ------------->|
          |    "192.168.1.1 kimde? 192.168.1.50'ye haber ver!"              |
          |                                                                 |
          |<-- (2) ARP Reply (Unicast: 52:54:00:12:34:56) ------------------|
          |    "192.168.1.1 bende, MAC adresim: 00:1A:2B:3C:4D:01"          |
          |                                                                 |
   [Önbellek Güncellenir: 192.168.1.1 -> 00:1A:2B:3C:4D:01]


2. ARP ZEHİRLEME (CACHE POISONING / SPOOFING) SALDIRISI
--------------------------------------------------------------------------------
                      +-----------------------------+
                      |     Saldırgan (Attacker)    |
                      |     IP:  192.168.1.66       |
                      |     MAC: AA:BB:CC:DD:EE:FF  |
                      +-----------------------------+
                                /         \
       Sahte ARP Reply (Zehirleme)       Sahte ARP Reply (Zehirleme)
      "192.168.1.1 benim MAC'imdir"     "192.168.1.50 benim MAC'imdir"
                              /             \
                             v               v
           +--------------------+         +--------------------+
           | Kurban İstemci A   |         | Ağ Geçidi (Router) |
           | 192.168.1.50       |         | 192.168.1.1        |
           +--------------------+         +--------------------+
           [Zehirlenmiş Önbellek]         [Zehirlenmiş Önbellek]
           192.168.1.1 -> [AA:BB:CC]      192.168.1.50 -> [AA:BB:CC]
                     \                           /
                      ====== TÜM TRAFİK ========
                             SALDIRGANDAN GEÇER! (Man-in-the-Middle)
