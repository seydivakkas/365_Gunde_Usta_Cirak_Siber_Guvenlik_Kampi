|                                                                                      |
|   [TCKN Doğrulayıcı]  ---> 10. ve 11. Basamak Kontrol Formülü:                       |
|                            c10 = ((Tekler*7) - Çiftler) % 10                         |
|                            c11 = (İlk 10 Basamak Toplamı) % 10                       |
|                                                                                      |
|   [Kart Doğrulayıcı]  ---> ISO/IEC 7812 Luhn (Mod-10) Algoritması:                  |

|                            Toplam % 10 == 0 şartı                                    |
|                                                                                      |
|   [IBAN Doğrulayıcı]  ---> ISO 7064 MOD-97 Algoritması:                              |
|                            İlk 4 hane sona, Harfler -> Sayı (A=10..Z=35)             |
|                            Büyük Sayı % 97 == 1 şartı                                |
