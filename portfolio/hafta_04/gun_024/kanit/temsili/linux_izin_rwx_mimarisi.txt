1. POSIX İZİN BLOĞU VE BİT DÜZEYİ TEMSİLİ

   Dosya Türü    Kullanıcı (u)       Grup (g)        Diğerleri (o)
   [ - / d / l ]   [ r  w  x ]      [ r  w  x ]       [ r  w  x ]
        |            |  |  |          |  |  |           |  |  |
        |            4  2  1          4  2  1           4  2  1
        |            \_____/          \_____/           \_____/
        |             User             Group             Other
        |            Toplam: 7        Toplam: 5         Toplam: 5  ==> Oktal: 0755
        v
  - = Normal Dosya
  d = Dizin
  l = Sembolik Bağ (Symlink)

2. ÖZEL İZİN BİTLERİ (SPECIAL PERMISSION BITS)
   ---------------------------------------------------------------------------
   Özel Bit      Oktal Değer    Sembolik Etki         Güvenlik Anlamı / Riski
   ---------------------------------------------------------------------------
   SUID          4000           rwsr-xr-x (User 's')   Dosyayı sahibinin yetkisiyle
                                                      (genellikle root) çalıştırır.
                                                      Yetki yükseltme (PrivEsc) riski!
   SGID          2000           rwxr-sr-x (Group 's')  Dizinde açılan dosyalar grubun
                                                      sahipliğini alır.
   Sticky Bit    1000           rwxrwxrwt (Other 't')  /tmp dizininde herkes yazabilir
                                                      fakat sadece dosya sahibi silebilir.
                                                      Dosya gaspı/tahrifatını önler.

3. UMASK MATEMATİĞİ (BITWISE AND-NOT)

   Taban Dosya İzni  : 0666  (rw-rw-rw-)  [İkili: 110 110 110]
   Umask Değeri      : 0022  (----w--w-)  [İkili: 000 010 010]
   Tersi (~Umask)    : 0755  (rwxr-xr-x)  [İkili: 111 101 101]
   ---------------------------------------------------------------------------
   Sonuç Dosya İzni  : 0644  (rw-r--r--)  [0666 & ~0022] (Güvenli Standart)

   Güçlendirilmiş Sunucu Modeli:
   Taban Dosya İzni  : 0666  (rw-rw-rw-)
   Umask 027         : 0027  (----w-rwx)
   Sonuç Dosya İzni  : 0640  (rw-r-----)  (CIS Benchmark - Diğerleri Sıfır Yetki)
