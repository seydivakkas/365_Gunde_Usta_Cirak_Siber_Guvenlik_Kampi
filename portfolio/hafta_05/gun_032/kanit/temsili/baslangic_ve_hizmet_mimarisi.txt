| SALDIRI VE KALICILIK (PERSISTENCE) RİSK NOKTALARI                                    |
+---------------------------------------------------------------------------------------+
|                                                                                       |
|  [1] Tırnaksız Servis Yolu (Unquoted Service Path - T1574.009)                        |
|      Örnek: C:\Program Files\Vulnerable App\service.exe                               |
|      Zafiyet: SCM sırasıyla C:\Program.exe, C:\Program Files\Vulnerable.exe arar.     |
|      Sonuç  : SYSTEM yetkisinde ayrıcalık yükseltme (LPE).                            |
|                                                                                       |
|  [2] Kayıt Defteri Otomatik Başlatma (Registry Run Keys - T1547.001)                 |
|      Konum: HKLM\...\Run | HKCU\...\Run                                               |
|      Zafiyet: Kullanıcı dizinlerinden (Temp, AppData) gizlice arka plan çalıştırma.   |
|                                                                                       |
|  [3] İsim Sahteciliği ve Benzetme (Masquerading - T1036)                             |
|      Örnek: svch0st.exe, lsasss.exe, System32 dışındaki sahte ikililer.               |
|      Zafiyet: Analistleri yanıltma, güvenlik operasyonlarını körleştirme.             |
|                                                                                       |
|  [4] Savunmayı Zayıflatma (Impair Defenses - T1562.001)                               |
|      Örnek: WinDefend, MpsSvc servislerini Stopped / Disabled yapma.                 |
|      Zafiyet: Güvenlik duvarı ve antivirüs motorunu devre dışı bırakarak yayılma.     |
|                                                                                       |
+---------------------------------------------------------------------------------------+
| DEFANSİF EN İYİ UYGULAMALAR (DEFENSIVE BEST PRACTICES)                               |
+---------------------------------------------------------------------------------------+
|  1. Bütün servis dosya yollarını mutlaka çift tırnak içine alınız.                    |
|  2. En az ayrıcalık (Least Privilege): Servisleri zorunlu olmadıkça SYSTEM ile değil,|
|     NETWORK SERVICE, LOCAL SERVICE veya sanal hesaplarla (Virtual Accounts) çalıştırın.|
|  3. Gelişigüzel hizmet kapatmayın; bağımlılık zincirini bozarak kararsızlık yaratmayın|
|  4. Kayıt defteri Run anahtarlarını ve Scheduled Task listelerini Sysinternals       |
|     Autoruns ve EDR ajanları ile sürekli taban çizgisi (baseline) farkına tabi tutun.|
