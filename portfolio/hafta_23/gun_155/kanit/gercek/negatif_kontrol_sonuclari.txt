[*] Senaryo: SCN-WEB-02 - İstemci Tarafı Rol ve Yetki Manipülasyonu (Privilege Escalation)
    Açıklama: İstemci kayıt veya profil güncelleme isteği gövdesinde sunucuya 'role: admin' parametresi enjekte etmiştir. Sunucu bu parametreyi doğrulamadan veritabanına yazarsa dikey yetki yükselme gerçekleşir.
    Hesaplanan Güvenlik Skoru : 40.0 / 100
    Güvenlik Kararı           : UYGUNSUZ / TEHLİKELİ
    [+] Tespit Edilen İhlal: ClientSideTrustAssumption (KRITIK) - İstemcinin sunucuya doğrudan güvenilmeyen yetki/fiyat verisi gönderdiği tespit edildi: 'role=admin'.
    [+] DURUM: BAŞARILI (Güven sınırı ihlali tam isabetle yakalandı).

    Güvenlik Kararı           : UYGUNSUZ / TEHLİKELİ
    [+] Tespit Edilen İhlal: ClientSideTrustAssumption (KRITIK) - İstemcinin sunucuya doğrudan güvenilmeyen yetki/fiyat verisi gönderdiği tespit edildi: 'price=0.01'.
    [+] DURUM: BAŞARILI (Güven sınırı ihlali tam isabetle yakalandı).

[*] Senaryo: SCN-WEB-04 - URI Yolu Üzerinde Dizin Atlama (Path Traversal Attempt)
    Açıklama: İstemci dosya indirme veya statik dosya çağrısında '../' ve '%2e%2e%2f' kalıplarıyla web kök dizini dışına çıkmaya çalışmıştır.
    Hesaplanan Güvenlik Skoru : 52.0 / 100
    Güvenlik Kararı           : UYGUNSUZ / TEHLİKELİ
    [+] Tespit Edilen İhlal: PathTraversalAttempt (KRITIK) - İstek yolunda potansiyel dizin atlama (Path Traversal) kalıbı saptandı: '/download/../../../../etc/shadow'.
    [+] DURUM: BAŞARILI (Güven sınırı ihlali tam isabetle yakalandı).

[*] Senaryo: SCN-WEB-05 - URL Sorgu Parametrelerinde Gizli Anahtar ve Parola İfşası
    Açıklama: İstemci API isteklerinde API anahtarını veya oturum parolasını GET URL sorgu dizesinde (?api_key=...&password=...) taşımaktadır; bu parametreler web sunucu erişim günlüklerine ve üçüncü taraf Referrer başlıklarına sızar.

    Güvenlik Kararı           : UYGUNSUZ / TEHLİKELİ
    [+] Tespit Edilen İhlal: SensitiveDataInQueryString (YUKSEK) - URL sorgu parametrelerinde hassas kimlik bilgisi tespit edildi: 'api_key' (Erişim günlüklerine ve Referrer başlıklarına sızar).
    [+] DURUM: BAŞARILI (Güven sınırı ihlali tam isabetle yakalandı).
