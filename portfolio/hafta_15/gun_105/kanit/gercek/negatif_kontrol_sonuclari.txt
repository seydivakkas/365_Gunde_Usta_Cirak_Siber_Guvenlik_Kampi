[NEG_01_BROKEN_HASH_ALGORITHM]
  Tanım         : Güvensiz veya kırılmış MD5 / SHA-1 algoritması ile manifest üretimi denemesi
  Güvenlik Eşiği: CWE-328: Use of Weak Hash
  Beklenen Hata : BrokenHashAlgorithmError
  Yakalana Hata : BrokenHashAlgorithmError
  Sonuç         : PASS (ENGELLENDİ)

[NEG_02_HMAC_SEAL_FORGERY]
  Tanım         : Manifest dosyasının mühür imzasının tahrif edilmesi veya sahte HMAC etiketi
  Güvenlik Eşiği: CWE-353: Missing Support for Integrity Check
  Beklenen Hata : ManifestTamperingError
  Yakalana Hata : ManifestTamperingError
  Sonuç         : PASS (ENGELLENDİ)

[NEG_03_PATH_TRAVERSAL_IN_MANIFEST]
  Tanım         : Manifest içinde üst dizinlere sızma denemesi (Örn: '../../windows/system32')
  Güvenlik Eşiği: CWE-22: Improper Limitation of a Pathname to a Restricted Directory
  Beklenen Hata : PathTraversalError
  Yakalana Hata : PathTraversalError
  Sonuç         : PASS (ENGELLENDİ)

[NEG_04_SYMLINK_ESCAPE_ATTEMPT]
  Tanım         : Kök dizin dışına işaret eden güvensiz sembolik bağ (symlink) tespiti
  Güvenlik Eşiği: CWE-59: Improper Link Resolution Before File Access
  Beklenen Hata : SymlinkEscapeError
  Yakalana Hata : SymlinkEscapeError
  Sonuç         : PASS (ENGELLENDİ)

[NEG_05_EMPTY_ROOT_DIRECTORY]
  Tanım         : Mevcut olmayan veya geçersiz kök dizin yolu iletimi
  Güvenlik Eşiği: CWE-73: External Control of File Name or Path
  Beklenen Hata : DirectoryNotFoundError
  Yakalana Hata : DirectoryNotFoundError
  Sonuç         : PASS (ENGELLENDİ)

[NEG_06_CORRUPTED_FILE_HASH]
  Tanım         : Diskteki bir dosyanın içeriğinin değiştirilmesi sonucu hash uyuşmazlığı tespiti
  Güvenlik Eşiği: CWE-354: Improper Validation of Integrity Check-value
  Beklenen Hata : FileIntegrityMismatchError
  Yakalana Hata : FileIntegrityMismatchError
  Sonuç         : PASS (ENGELLENDİ)

[NEG_07_NULL_BYTE_PATH_INJECTION]
  Tanım         : Dosya veya dizin yolunda zararlı Null-Byte (0x00) zehirlemesi denemesi
  Güvenlik Eşiği: CWE-158: Improper Neutralization of Null Byte or Special Characters
  Beklenen Hata : NullByteInjectionError
  Yakalana Hata : NullByteInjectionError
  Sonuç         : PASS (ENGELLENDİ)

[NEG_08_OVERSIZED_FILE_READ_DOS]
  Tanım         : 1 MB tavanını aşan devasa dosya girdisi ile bellek tüketimi saldırısı (DoS)
  Güvenlik Eşiği: CWE-400: Uncontrolled Resource Consumption
  Beklenen Hata : PayloadLimitExceededError
  Yakalana Hata : PayloadLimitExceededError
  Sonuç         : PASS (ENGELLENDİ)

[NEG_09_TYPE_CONFUSION]

  Güvenlik Eşiği: CWE-843: Access of Resource Using Incompatible Type
  Beklenen Hata : TypeValidationError
  Yakalana Hata : TypeValidationError
