[NEG_01_UNSALTED_HASH_STORAGE]
  Tanım         : Kullanıcı parolasının tuzlama yapılmaksızın düz hash ile saklanması
  Güvenlik Eşiği: CWE-759: Use of a One-Way Hash without a Salt
  Beklenen Hata : UnsaltedHashError
  Yakalana Hata : UnsaltedHashError
  Sonuç         : PASS (ENGELLENDİ)

[NEG_02_INSUFFICIENT_ITERATIONS]
  Tanım         : Kriptografik kabul eşiğinin (100.000) altında kalan yetersiz PBKDF2 iterasyonu
  Güvenlik Eşiği: CWE-916: Use of Password Hash With Insufficient Computational Effort
  Beklenen Hata : InsufficientIterationsError
  Yakalana Hata : InsufficientIterationsError
  Sonuç         : PASS (ENGELLENDİ)

[NEG_03_SHORT_SALT_LENGTH]
  Tanım         : 16 bayt (128 bit) tavanının altında kalan güvensiz kısa tuz (salt) kullanımı
  Güvenlik Eşiği: CWE-326: Inadequate Encryption Strength
  Beklenen Hata : InsecureSaltLengthError
  Yakalana Hata : InsecureSaltLengthError
  Sonuç         : PASS (ENGELLENDİ)

[NEG_04_PREDICTABLE_SALT_VALUE]
  Tanım         : Statik veya tahmin edilebilir sabit tuz kullanımı (Örn: '1234567812345678')
  Güvenlik Eşiği: CWE-760: Use of a One-Way Hash with a Predictable Salt
  Beklenen Hata : PredictableSaltError
  Yakalana Hata : PredictableSaltError
  Sonuç         : PASS (ENGELLENDİ)

[NEG_05_PEPPER_MISMATCH_VERIFY]
  Tanım         : Biber (pepper) ile kilitlenmiş parola kaydının yanlış pepper ile doğrulanması
  Güvenlik Eşiği: CWE-345: Insufficient Verification of Data Authenticity
  Beklenen Hata : PasswordVerificationMismatchError
  Yakalana Hata : PasswordVerificationMismatchError
  Sonuç         : PASS (ENGELLENDİ)

[NEG_06_PASSWORD_MISMATCH_VERIFY]
  Tanım         : Kullanıcı parola doğrulamasında hatalı parola girişi yapılması
  Güvenlik Eşiği: CWE-208: Observable Timing Discrepancy
  Beklenen Hata : PasswordVerificationMismatchError
  Yakalana Hata : PasswordVerificationMismatchError
  Sonuç         : PASS (ENGELLENDİ)

[NEG_07_NULL_BYTE_INJECTION]
  Tanım         : Parola veya tuz alanında Null-Byte (0x00) zehirlemesi denemesi
  Güvenlik Eşiği: CWE-158: Improper Neutralization of Null Byte or Special Characters
  Beklenen Hata : NullByteInjectionError
  Yakalana Hata : NullByteInjectionError
  Sonuç         : PASS (ENGELLENDİ)

[NEG_08_OVERSIZED_PASSWORD_DOS]
  Tanım         : 1 MB tavanını aşan devasa parola girdisi ile bellek tüketimi saldırısı (DoS)
  Güvenlik Eşiği: CWE-400: Uncontrolled Resource Consumption
  Beklenen Hata : PayloadLimitExceededError
  Yakalana Hata : PayloadLimitExceededError
  Sonuç         : PASS (ENGELLENDİ)

[NEG_09_TYPE_CONFUSION]
  Tanım         : Parola yerine tamsayı veya sözlük tipi iletilmesi
  Güvenlik Eşiği: CWE-843: Access of Resource Using Incompatible Type
  Beklenen Hata : TypeValidationError
  Yakalana Hata : TypeValidationError
  Sonuç         : PASS (ENGELLENDİ)
